# 프로젝트 리뷰 항목 (🟩 특화 — mini-dbms)

- 오류 반환 경로마다 `malloc`한 메모리, 연 파일, 잡은 잠금을 정리하는가 (특히 `table`, `db`, `server`)
- 테이블 상태(파일 끝 위치, 다음 `id`, B+ 트리)를 읽거나 바꾸는 코드가 테이블 잠금 안에 있는가. `INSERT`가 읽기 잠금으로 내려가 있지 않은가
- 파일 접근에 `pread`/`pwrite`가 아닌 것(`lseek`, `read`, `fread`)을 썼는가
- 고정 길이 레코드의 경계를 지키는가 (`VARCHAR(n)` 길이 검사, NUL 채움, 버퍼 크기)
- B+ 트리 분할 뒤 리프 연결 리스트와 부모 키가 맞는가 (`bpt_validate`를 부르는 테스트가 있는가)
- 클라이언트가 보낸 길이·개수(헤더 크기, 본문 길이, `LIMIT`)를 검사 없이 버퍼 크기나 반복 횟수로 쓰는가
- CLI와 서버 중 한쪽에만 실행 로직을 넣었는가 (둘 다 `db_execute()`를 불러야 함)
